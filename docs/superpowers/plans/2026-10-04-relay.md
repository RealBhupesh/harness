# Relay Implementation Plan

> For agentic workers: execute tasks natively in milestone order, using test-first cycles and verified commits.

**Goal:** Build a resumable agent harness with an offline, independently verified task loop.
**Architecture:** Zod schemas feed a provider-agnostic orchestrator; filesystem checkpoints and Markdown preserve continuation. Restricted tools and Git isolate task execution; verification gates commits.
**Tech Stack:** TypeScript, Node >=20.19, pnpm 10.32.1, Vitest, Zod, better-sqlite3.
**Spec:** ../specs/2026-10-04-relay-design.md and ../../REQUIREMENTS.md.

## Global constraints

Strict TypeScript, no heavy agent frameworks; human-approved destructive operations; at most three attempts; no secrets in persisted content; checkpoint every transition.

## Review focus

- Escaping paths/symlinks and command arguments: reject before running tools.
- Crashes during commit/merge: resume without duplicate work or commits.
- Cyclic or completed-task-changing plans: fail validation.
- False worker success and absent acceptance evidence: fail verification.
- Provider/network failures and exhausted budgets: checkpoint and stop cleanly.

## Milestones and files

- [ ] M0: package/tooling/CI, AGENTS.md, GOAL.md, .relay/ handoff; prove dependency-backed schema checks run.
- [ ] M1: src/schema.ts, memory.ts, provider.ts, tools.ts, git.ts, orchestrator.ts, cli.ts; test validated task graphs, confined tools, and a mock goal reaching a real Git commit.
- [ ] M2: src/verifier.ts and questions.ts; test rejection, retry, three-attempt blocking, independent work and human answers.
- [ ] M3: durable checkpoints/locking; test actual child-process SIGKILL at phase boundaries and resume exactly once.
- [ ] M4: provider adapters, routing, metering/budgets; test mocked HTTP protocols, timeout/error handling and cap stops. No live calls without credentials.
- [ ] M5: SQLite/JSONL observability, status/trace/report commands; verify records survive restart and HTML escapes untrusted text.
- [ ] M6: optional worktree coordinator, full-suite regression rollback and conflict requeue; keep serial behavior working.
- [ ] M7: eval scorecard and disabled scheduled workflow; run real fixtures against MockProvider.
- [ ] M8: plan actual GOAL.md only when human replaces placeholder; otherwise record this exact external blocker.

For each task: write tests, observe the missing behavior fail, implement its interface, run the full check suite, update handoff, commit. Continue through verified milestones; persist unfinished work rather than claim completion.
